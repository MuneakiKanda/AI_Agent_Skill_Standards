# 共通Skill設計標準（初版草案）

1. **入口と責務** — `SKILL.md` に適用条件、処理順序、必要な確認、完了条件を書く。
2. **段階的開示** — 工程別の詳細手順や判断例は `references/` に、再利用する形式はテンプレートに置く。本文に各参照先と読み込む条件・タイミングを書く。
3. **必須の安全条件** — 承認が必要な操作、禁止事項、停止条件を本文に置く。必須参照が欠落または読み込み不能なら、その参照に依存する処理を止め、原因を報告する。任意参照の代替手順がある場合は本文に記載する。
4. **実行環境の確認** — 対象製品とバージョンを特定し、読み込み上限、サイズの計測方法、権限、検証・配布手順を製品別規約に記録する。
5. **受け入れ基準** — 配布前に、本文の必須指示が読み込まれること、必須参照が必要な工程で解決できること、参照欠落時に依存処理が止まることを確認する。利用できる場合は対象環境の厳格検証を実施し、検証結果と対象バージョンを記録する。
