# Antigravity CLI 実装規約（初版草案）

[共通Skill設計標準](../standards/skill-design.md)を適用する。

- **検証記録** — Plugin v0.3.1 の `session-handoff` で、`agy plugin validate <plugin-path> --strict` が本文 26,301 バイトのうち先頭 24,000 バイトだけを読み込むと報告した。CLI のバージョンは未記録。対象バージョンを変える際は上限と計測対象を再確認する。
- **本文の設計目標** — この事例では保守の余裕を取るために 20,000 バイト以内を暫定目標とする。
- **配布前の検証** — 対象環境の厳格検証で終了コード 0 と読み込み切り捨て警告がないことを確認し、必須参照と停止条件を実行時に確認する。
- **権限と配布** — 対象バージョンの権限・承認の挙動とインストール・更新手順を確認後に追記する。
